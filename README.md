# Web Design class site

Live at **https://montverde-webdesign.github.io/**

This repository is the class hub: the Home, Assignments, and Submissions pages.
Only the teacher edits it. Each student's section is its own repository in this
organization, published at `https://montverde-webdesign.github.io/<section-name>/`.

## Files

| File | What it is |
| --- | --- |
| `index.html` | Home page: course name and description |
| `assignments.html` | Every assignment, newest first, with where to post it |
| `submissions.html` | Links to every student's section |
| `style.css` | Styles for all three pages |

## Common edits

- **New assignment:** in `assignments.html`, copy an `<article class="assignment">` block to the top of the list and change it.
- **New student:** in `submissions.html`, copy an `<li>` line in the `students` list and change the link and first name.
