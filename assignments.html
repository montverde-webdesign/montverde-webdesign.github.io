How to post your work

  1. Open your section in VS Code: File → Open Recent and pick your section folder (for example, jane-d).
  2. In the sidebar, open the folder the assignment says: warm-ups, classwork, or projects.
  3. Right-click template.html in that folder → Copy. Then right-click the same folder → Paste. A file named template copy.html appears.
  4. Right-click template copy.html → Rename (or press F2) and type the exact file name from the assignment, like 2026-10-23-css-rule.html.
  5. Open your new file and fill in the title, heading, date, and your work.
  6. Open that folder's index.html. Copy one line from the list, paste it at the top of the list, and change the link and the text to match your new page.
  7. Check it in Live Server: click from your section home, to the folder, to your new page, and back.
  8. In Source Control, commit with a message like Add Oct 23 CSS warm-up, then click Sync Changes.
  9. Wait about a minute, then check your live section and hard-refresh with Ctrl+Shift+R.

File name rules: the date first (year-month-day), then a short title, all lowercase, with dashes instead of spaces. For example: 2026-10-23-css-rule.html. Putting the date first keeps your files in order.
